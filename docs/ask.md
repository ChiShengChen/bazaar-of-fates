# 問事 · Divination on demand（奇門・六壬・梅花・六爻・小六壬）

排盤的另一半：不看生辰，看**問的那一刻**。傳統上奇門、六壬、梅花、六爻、小六壬本來就是「有事才起」的術數——以問事的時刻（或你報的數、說的話、擲的錢）起局，再依所問之事找用神。

```bash
bazaar ask qimen  "明天面試會順利嗎"                         # 以此刻起時盤；--at 2026-10-10T14:30 指定時刻；--place 台北
bazaar ask liuren "這筆投資能做嗎" --read                     # 時課＋解讀
bazaar ask iching "他會回我嗎" --numbers 3,7,9                # 梅花 數字起卦（1–3 個數）
bazaar ask iching "他會回我嗎" --text "他會回我嗎"             # 梅花 字占
bazaar ask liuyao "合約能簽嗎" --coins 7,8,9,8,6,7            # 六爻 金錢卦（自初爻起；6 老陰、9 老陽 動）
bazaar ask xiaoliuren "今天出門順嗎"
```

API `POST /ask/{system}`（body：`question`, `at?`, `tz_offset_hours`, `place?`, `numbers?`, `text?`, `coins?`, `qimen_method`, `read`, `lang`）、MCP tool `ask`、Space 的 **問事 Ask** 分頁，都走 [`fortune/ask.py`](../fortune/ask.py)。問題會先分題（事業／財運／感情／健康／學業／家庭／一般），用神依題而定。回傳：`chart`（含 `reasoning_chain` 起局步驟）、`verdict`（`verdict_zh` 吉／平／凶、`score`、`reasons` 每一分的依據、`facts`、`timing_hint` 應期、奇門另有 `lucky_directions`）、`summary`，`read=true` 加該術數的解讀（問題導向）。

## 起局方式

| 系統 | 預設 | 另可 |
|---|---|---|
| 奇門 `qimen` | 時盤：問事時刻的時家奇門（拆補；`qimen_method=zhirun` 置閏） | — |
| 六壬 `liuren` | 時課：月將加占時（占時＝問事時辰） | — |
| 梅花 `iching` | 時間起卦（農曆年月日時） | `numbers`：三數＝上、下、動爻；雙數＝上、下，動爻＝和；單數＝前半為上、後半為下，動爻＝和（個位數：上下同卦）。`text` 字占：字數少為上、多為下（偶數對半），動爻＝總字數＋時辰數 |
| 六爻 `liuyao` | 時間起卦（與梅花同卦，納甲） | `coins`：六個 6／7／8／9 自初爻起（6 老陰、9 老陽為動）；多爻動以上爻為變爻，其餘標「亦動」 |
| 小六壬 `xiaoliuren` | 農曆月日時 | — |

## 判斷規則（每一分列在 `reasons`）

**奇門**：日干落宮＝求測人、時干落宮＝所問之事（甲以旬首儀代）、用神依題：事業 開門・財 生門・感情 六合・病 天芮・學業 天輔・家宅 生門・一般 值使門。
用神宮：三吉門 +1／凶門 −1；門迫（門剋宮）−1；吉星（輔心任沖）+0.5／凶星（蓬芮柱）−0.5（病占天芮不扣）；吉神（符天合陰地）+0.5／凶神（虎玄蛇）−0.5；三奇 +0.5；臨庚 −0.5；落時旬空亡 −1。所問之事宮同評。事宮生人宮 +1、比和 +0.5、人剋事 +0.5、人生事 −0.5、事剋人 −1、同宮 +0.5。吉方＝三吉門所在方位；應期＝用神宮地支。

**六壬**：類神依題（官＝剋日干之支、財＝日干所剋、父＝生日干；感情兼看六合／天后，學業看朱雀，病看白虎／螣蛇）入三傳 +1、不入 −0.5；末傳生／比日干 +1、剋日干 −1、日干生末傳 −0.5、日干剋末傳 +0.3；本題吉將 +1、凶將 −0.5／將（病占虎蛇 −1）；課體：元首／知一／比用 +0.5、重審 −0.5、返吟 −0.5、伏吟／八專／別責 註記；初傳落日旬空 −1。應期＝末傳之日時。

**梅花**：體用關係（比和、用生體 吉 +2；體剋用 小吉 +1；體生用、用剋體 凶 −2）＋變卦後的用卦對體（吉 +1／小吉 +0.5／凶 −1）；互卦為過程。應期＝用卦五行之日月或動爻數。

**六爻**：用神依題（事業 官鬼、財 妻財、學業 父母、家庭 父母子孫；感情／健康／一般看世爻）：旺相／日生／日臨 +1、休囚／日剋 −1、月破／旬空 −1；用神不上卦 −1（列伏神）；動爻化回頭生／進神 +1、回頭剋／退神 −1、化洩 −0.5；世爻強弱 ±0.5；世應相沖 −0.5／相合 +0.5；病占官鬼動 −1、子孫動 +1、官鬼旺 −1；財占／情占兄弟動 −1。應期＝用神值日月或合沖之時。

**小六壬**：大安、速喜、小吉 為吉（+2），留連、赤口、空亡 為凶（−2）。

分級：≥2 吉、≤−1.5 凶、其餘平。
