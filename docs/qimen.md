# 奇門遁甲圖解 · Qi Men Dun Jia Visual Guide

「三式」之一：把時間排成**九宮格 + 八門**的局，看當下的格局與值符門。
One of the Three Cosmic Boards (三式): time is laid into a **nine-palace grid with eight gates**; you read the layout and the on-duty gate.

> 開啟 / Open: 首頁選 **Qi Men Dun Jia · 奇門遁甲**。

## 怎麼讀 / Reading the board

```
 九宮（3×3）：八門安入八宮，中宮寄
 陽遁 / 陰遁 · 第幾局 · 值符門（開/休/生/傷/杜/景/死/驚）
```

- **陽遁 / 陰遁**：依節氣半年定順逆。
- **局數**：一到九局，定起盤方式。
- **值符門**：當下「當值」的門，**開門/休門/生門**為吉，**傷/死/驚**多凶。

## 起局 / How the chart is cast（時家奇門・轉盤・拆補法）

1. **節氣**：以出生時刻所在的節氣（24 節氣精確到分）定**陽遁**（冬至→芒種）或**陰遁**（夏至→大雪）。
2. **元**：由日柱的**符頭**（最近的甲或己日）定上／中／下元：甲子 甲午 己卯 己酉＝上元，甲寅 甲申 己巳 己亥＝中元，甲辰 甲戌 己丑 己未＝下元。
3. **局數**：節氣 × 元 查表（例：芒種上元六局）。
4. **地盤**：六儀三奇 戊己庚辛壬癸丁丙乙 從局數宮起，陽遁順、陰遁逆布九宮。
5. **時干支**：五鼠遁；23 時後以次日子時計。時干支所在旬的旬首遁儀落何宮，該宮之星為**值符**、之門為**值使**（中宮寄坤二）。
6. **天盤**：值符隨時干落宮，九星與天盤干同步旋轉；值使隨時支（自旬首支數至時支，陽順陰逆）飛宮，八門同步旋轉；八神自值符宮起，陽順陰逆。

九宮格每格顯示：八神・九星・八門・天盤干／地盤干；值符宮加框，吉門綠框、凶門紅框。
