## 起課 / How the course is cast

1. **月將**：太陽所躔之宮（子＝寶瓶 … 戌＝白羊 … 亥＝雙魚），以出生精確時刻的太陽黃經求得。
2. **月將加時**：月將加於占時（出生時辰）之上起天地盤；天盤上神 ＝ 地盤支 ＋ 月將 − 占時。
3. **四課**：日干寄宮上神（甲寅 乙辰 丙巳 丁未 戊巳 己未 庚申 辛戌 壬亥 癸丑）、其上神；日支上神、其上神。
4. **三傳**：賊克法——先取下賊上，次取上克下；多課相剋以**比用**（上神陰陽與日干相同者）決之；無賊克或伏吟、返吟、涉害等課體尚未實作，暫以日支上神為初傳並在排盤步驟註明。
5. 初傳與日主之五行生剋定吉凶。

## 九宗門 / The nine course types

依標準順序判課體：**賊克**（下賊上＝重審、上克下＝元首）→ **比用**（知一）→ **涉害**（計上神自所乘地盤回本家所經之剋，深者為用；相等取孟、次仲）→ **遙克**（蒿矢／彈射）→ **昴星**（陽日虎視：酉上神；陰日冬蛇掩目：酉下神）→ **別責**（一課不備：陽日取干合寄宮上神、陰日取支三合次支）→ **八專**（干支同位）；**伏吟**（有剋取剋，無剋陽日干上神／陰日支上神，中末取刑）與**返吟**（有剋取剋，無剋取驛馬）優先判定。排盤步驟會寫出課體名稱與所用規則。
