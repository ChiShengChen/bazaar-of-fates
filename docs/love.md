# 感情專科 · The love-specialist reader

一位**只看感情**的命理師：同一個生辰，不再問「整體運勢」，而是把 13 套系統裡所有跟感情有關的結構拉出來，分成三層——**命**（原局怎麼愛）、**運**（哪幾年是桃花年／婚緣年）、**合**（兩個人合不合）——每一分都列出依據，最後才由 AI 以「感情命理師」的口吻解讀，先回答你問的那個子題。

```bash
bazaar love 1990-06-15 14:30 --gender female --place 台北 --ask "我什麼時候會遇到正緣" --years 8 --read
bazaar love 1990-06-15 14:30 --gender female --partner-date 1988-11-03 --partner-time 08:15 --partner-gender male   # 合婚
```

API `POST /love`（`birth`, `question`, `partner?`, `start_year?`, `years`, `read`, `lang`）、MCP tool `love`、Space 的 **Love 感情專科** 分頁都走同一支 `fortune/love.py`。性別會改變配偶星（男命財星為妻、女命官殺為夫），請盡量填。

## 問題分類 / Sub-intents

| 子題 | 觸發字（節錄） | 解讀先講什麼 |

## 解讀 / The reading

`fortune/prompts/love/love_master.md` 是這位命理師的人設：只讀事實、先答子題、命→運→合、點名證據（「流年丁未透七殺」「Venus square Saturn 2.1°」）、各門派相左時各自解釋、不說「註定」、不替人決定分合、涉及安全時直接建議求助。沒接 LLM 時回傳事實摘要。

> ⚠️ 僅供文化、教育與娛樂用途。感情由兩個人經營，命盤只說傾向與時機。
