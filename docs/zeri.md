# 擇日與流日 · Date picking & daily outlook

在首頁選 **Dates 擇日 · 今日**，填出生資料、目的（結婚／開業／搬家／簽約／手術／出行／求財／一般）與日期區間（最多 121 天），按 **Pick dates**。每一天都會依下列規則打分，日曆上以顏色分級（★5 上吉 → ★1 忌），點任一天看依據、宜忌、流日、吉時與奇門吉方。**Today 今日運勢** 則是當天的同一套分析加大運流年流月脈絡。

## 評分規則 / Scoring（每項都列在「依據」裡，可核對）

| 來源 | 規則 |
|---|---|
| 黃曆（lunar-python） | 宜含本題 +2、忌含本題 −3；建除十二值宜 +1／不宜 −1；二十八宿吉 +0.5／凶 −0.5；吉神、凶煞每個 ±0.3（上限五個）；彭祖百忌命中 −1 |
| 八字流日 | 流日天干為喜用 +1.5／忌 −1；**沖本命日柱 −4**、**歲破（沖太歲）−3**、月破 −2、落本命日柱旬空 −1、六合／三合本命日支 +1；本題相關神煞（如結婚看紅鸞天喜、搬家出行看驛馬、開業看祿神）每個 +0.8，凶煞 −0.6 |
| 紫微流日（x-iztro） | 流日四化：化祿／權／科入本題宮位（結婚夫妻、開業官祿、搬家田宅、簽約求財財帛、手術疾厄、出行遷移）+1，化忌入 −1.5 |
| 奇門（時家，午時） | 值使門為三吉門 +1／凶門 −1；另列當日**吉方**（開休生門或乙丙丁三奇所在方位）與應避方位 |
| 小六壬 | 當日午時落宮吉 +0.5／凶 −0.5 |

分級：≥5 分 ★5 上吉、≥3 ★4 吉、≥1 ★3 可、≥−1 ★2 平、其餘 ★1 忌。**沖日柱或歲破的日子不論總分一律列為忌日**；手術若黃曆明忌亦列忌。

## 吉時 / Hours

最佳日期各列十二時辰：時支沖流日支 −2、沖本命日支 −2、合日支 +1、時干喜用 +1／忌 −0.5、該時辰奇門值使吉凶 ±1、小六壬 ±0.5；最高三個正分時辰標為吉時。

## 流日 / Daily pillars

八字流日（[bazi_ext.py](../fortune/bazi_ext.py) `liuri`／`liushi`）以當日正午的精確節氣取年月日柱，給出流日十神、藏干、納音、長生、旬空、神煞，以及與原局＋流年＋流月地支的刑沖合會；流時以五鼠遁取時柱。
